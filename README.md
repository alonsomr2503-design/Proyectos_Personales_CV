# Mis Proyectos Web

Colección de pequeños proyectos hechos con **HTML, CSS y JavaScript** mientras estudio el ciclo de Desarrollo de Aplicaciones Web (DAW). Cada carpeta es un proyecto independiente que se puede abrir directamente en el navegador.

## Proyectos

| Proyecto | Descripción | Demo | Código |
|----------|-------------|------|--------|
| 🎨 Portafolio personal | Portafolio con tema claro/oscuro, sección de estudios dinámica y formulario para añadir nuevos estudios | [Ver demo](https://alonsomariblanca.github.io/mis-proyectos-web/portafolio/) | [Carpeta](./portafolio) |
| 🐙 Buscador de perfiles de GitHub | Busca un usuario de GitHub y muestra su avatar, bio y repositorios públicos usando la API de GitHub | [Ver demo](https://alonsomariblanca.github.io/mis-proyectos-web/buscador-github/) | [Carpeta](./buscador-github) |

## Qué he practicado

- HTML semántico y accesibilidad (etiquetas ARIA, formularios con `label`)
- Diseño responsive con Flexbox, Grid y variables CSS
- Manipulación del DOM y eventos con JavaScript
- Consumo de APIs con `fetch` y `async/await`
- Persistencia ligera con `localStorage` (tema claro/oscuro)

## Cómo ejecutarlos

```bash
git clone https://github.com/alonsomariblanca/mis-proyectos-web.git
```

Abre el archivo `index.html` de la carpeta del proyecto que quieras ver en tu navegador. No hace falta instalar nada.
